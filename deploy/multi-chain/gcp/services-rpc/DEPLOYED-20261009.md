Keep the previous `b6dd702` release. Rollback state is root-only:
`/var/lib/parth/services-rpc-rollout/20261009T072859Z/state.json`.

```sh
ssh gcp-cp-ce 'sudo -n python3 /tmp/psy-services-rpc-31f7eb8-20261009/rollout.py rollback /var/lib/parth/services-rpc-rollout/20261009T072859Z/state.json'
```

Rollback validates current files, executable and old artifact before restarting
only Services. It retains a migration-disable-only EnvironmentFile, restoring
the original binary/provider configuration without running migrations. If any
guard fails, inspect the newer state; do not bypass it or overwrite other work.
The two new gateway listeners may remain idle; they do not replace existing ones.

## Reuse

This is a pinned, one-shot rollout, not an idempotent general upgrader. Before a
future release, take a new baseline and prepare/review a new immutable manifest
and overrides. Do not run the older combined updater, which restarts Indexers and
can run migrations. `source-versions.env` is a historical full-cohort manifest,
not authorization to replace this component with its old Services version.
